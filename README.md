Este projeto é uma aplicação de login desenvolvida com React e TypeScript. Ele utiliza autenticação via Firebase e oferece as seguintes funcionalidades principais:

- Cadastro de novos usuários
- Login e logout de usuários autenticados
- Proteção de rotas para páginas restritas (Dashboard)
- Exibição de alertas e feedback visual (Spinner)
- Estrutura modular com componentes reutilizáveis
- Página pública acessível sem autenticação
- A estrutura do projeto inclui páginas para login, cadastro, dashboard e home pública, além de componentes para inputs, alertas e rotas protegidas. O gerenciamento de autenticação é feito por meio de um provider dedicado, garantindo segurança e controle de acesso.
